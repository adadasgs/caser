# КЕЙСЕР

Адаптивный сайт с кейсами, апгрейдами и гостевыми агентами.

## Запуск локально
`npm install` затем `npm start`; откройте `http://localhost:3000`.

## Render и сохранение данных
Проект хранит состояние гостевых агентов на сервере в JSON-файле. Для сохранения файла после перезапусков Render нужен Persistent Disk, смонтированный в `/var/data`. Persistent Disk требует платный Web Service; бесплатный Render без диска не гарантирует сохранение данных после перезапуска или redeploy.

Гостевой ID создаётся автоматически в браузере без регистрации и пароля. Данные автоматически загружаются с сервера на том же браузере/устройстве. Для синхронизации между устройствами потребуется переносимый код агента или другой способ привязки.

Начисление +500 ₽ виртуальное; реальных платежей и вывода нет. Независимый проект, не связанный с CASER или Valve.
